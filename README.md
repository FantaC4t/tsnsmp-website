# TSNSMP Server Website

Welcome to the TSNSMP Server website project! This project serves as the official website for the TSNSMP Minecraft server, providing information, resources, and a platform for community engagement.

## Project Structure

The project is organized as follows:

```
tsnsmp-website
├── src
│   ├── index.html          # Main HTML file for the website
│   ├── css
│   │   ├── style.css      # Main styles for the website
│   │   └── responsive.css  # Responsive design styles
│   ├── js
│   │   ├── main.js        # Primary JavaScript functionality
│   │   └── animations.js   # JavaScript for animations
│   ├── pages
│   │   ├── about.html     # Information about the server
│   │   ├── rules.html     # Server rules and guidelines
│   │   ├── staff.html     # List of staff members
│   │   └── contact.html    # Contact information and form
│   └── assets
│       ├── logo           # Directory for the logo file
│       └── fonts          # Directory for custom fonts
├── package.json           # npm configuration file
└── README.md              # Project documentation
```

## Setup Instructions

1. **Clone the Repository**: 
   Clone this repository to your local machine using:
   ```
   git clone <repository-url>
   ```

2. **Navigate to the Project Directory**: 
   Change into the project directory:
   ```
   cd tsnsmp-website
   ```

3. **Install Dependencies**: 
   Install the necessary dependencies using npm:
   ```
   npm install
   ```

4. **Run the Project**: 
   Start the development server to view the website:
   ```
   npm start
   ```
